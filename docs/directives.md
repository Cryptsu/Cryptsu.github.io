# Custom Directives

This page features the list of custom directives I use for this blog.

### `::ytembed`

Embed `Youtube`'s video into the blog. **Usage**:

```markdown
::ytembed[Video's description]{#video-id}
```

### `:code`

Mark a markdown block formatted as inine code like `this`. **Usage**:

```markdown
:code[some-text-or-markdown bla bla bla]
```

### `:text`

You can create formatted text pieces! Currently only support `color` attributes.

```markdown
:text[some-text]{color=color-name}
```
